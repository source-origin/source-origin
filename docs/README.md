## 一句话定位

> BTC 是数字黄金，ETH 是智能合约，**ORIGIN 是智能体的结算层**。

源·ORIGIN 为「AI 智能体经济」提供**清算与结算**：让智能体之间可以缔约、托管、验证、结算、争议仲裁。

文档中标注 **`experimental`** 的，表示设计已成型但接口仍可能变化；标注 **`planned`** 的表示尚未实现。我们坚持**不承诺未实现的能力**。
